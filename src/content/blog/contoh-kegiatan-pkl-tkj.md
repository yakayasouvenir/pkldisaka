## Apa Saja Contoh Pekerjaan Anak TKJ Saat PKL?

Pekerjaan anak TKJ saat PKL dapat mencakup pemasangan sistem operasi, pemeriksaan perangkat keras, konfigurasi jaringan, pemeliharaan komputer, dan pemberian bantuan teknis kepada pengguna.

| Kegiatan | Kompetensi |
|---|---|
| Instalasi Windows | Pengelolaan sistem operasi |
| Perakitan komputer | Pengenalan perangkat keras |
| Crimping kabel UTP | Instalasi jaringan |
| Konfigurasi LAN | Pengalamatan jaringan |
| Konfigurasi router | Pengelolaan konektivitas |
| Troubleshooting | Analisis gangguan |
| Pemeliharaan komputer | Perawatan perangkat |
| Inventarisasi perangkat | Administrasi teknologi informasi |

Tidak semua siswa harus melakukan seluruh kegiatan tersebut. Jenis pekerjaan mengikuti kebutuhan perusahaan, kemampuan siswa, dan arahan pembimbing industri.

## Instalasi Sistem Operasi Windows

Instalasi Windows merupakan kegiatan pemasangan sistem operasi pada komputer yang mencakup persiapan perangkat, media instalasi, konfigurasi awal, pemasangan driver, dan pemeriksaan fungsi komputer.

Sebelum melakukan pekerjaan, siswa perlu memeriksa spesifikasi komputer dan kompatibilitas sistem operasi.

Data penting harus dicadangkan apabila komputer sebelumnya telah digunakan. Instalasi ulang tanpa persetujuan pengguna dapat menyebabkan kehilangan data.

Contoh penulisan kegiatan dalam laporan sebagai berikut.

Kegiatan instalasi sistem operasi dilakukan dengan mempersiapkan media instalasi yang telah disediakan oleh pembimbing. Setelah proses instalasi selesai, dilakukan pemeriksaan perangkat keras, pemasangan driver yang diperlukan, serta pengujian fungsi komputer.

Informasi resmi mengenai sistem operasi Windows dapat ditemukan melalui [Microsoft Support](https://support.microsoft.com/windows).

## Perakitan dan Pemeliharaan Komputer

Perakitan komputer mencakup pemasangan komponen perangkat keras, sedangkan pemeliharaan komputer bertujuan menjaga kondisi perangkat agar dapat berfungsi sesuai kebutuhan pengguna dan prosedur kerja.

Kegiatan perakitan dapat dimulai dengan pemeriksaan kompatibilitas komponen, pemasangan motherboard, prosesor, RAM, media penyimpanan, dan perangkat pendukung.

Sebelum menangani komponen internal, komputer perlu dimatikan dan sumber listrik dilepas. Gunakan prosedur perlindungan terhadap listrik statis sesuai arahan teknisi.

Pemeliharaan komputer dapat mencakup pembersihan debu, pemeriksaan kipas pendingin, pengecekan kondisi penyimpanan, dan pemeriksaan fungsi perangkat.

Dalam laporan, siswa dapat menjelaskan kondisi perangkat sebelum pekerjaan dilakukan dan hasil pemeriksaan setelah pekerjaan selesai.

Untuk kabel straight dengan standar T568B pada kedua ujung, susunan warna yang digunakan adalah sebagai berikut.

Setelah konektor terpasang, kabel diperiksa menggunakan LAN tester. Hasil pengujian digunakan untuk mengetahui apakah hubungan antarpin telah sesuai.

Pengujian kontinuitas menggunakan LAN tester sederhana tidak selalu membuktikan bahwa kabel memenuhi seluruh persyaratan performa jaringan.

## Bagaimana Contoh Kegiatan Konfigurasi Jaringan LAN?

Konfigurasi jaringan LAN mencakup pengaturan koneksi perangkat dalam jaringan lokal melalui penggunaan alamat IP, subnet mask, perangkat penghubung, dan pengujian komunikasi antarperangkat komputer.

Sebagai contoh simulasi, dua komputer dapat menggunakan konfigurasi berikut.

| Pengaturan | Komputer A | Komputer B |
|---|---|---|
| IP Address | 192.168.10.10 | 192.168.10.11 |
| Subnet Mask | 255.255.255.0 | 255.255.255.0 |
| Jaringan | 192.168.10.0/24 | 192.168.10.0/24 |

Topologi simulasi menghubungkan kedua komputer melalui sebuah switch.

Pengujian koneksi dari Komputer A menuju Komputer B dapat menggunakan perintah berikut.

```bash
ping 192.168.10.11
```

Apabila perangkat memberikan respons, komunikasi ICMP antarkomputer berhasil pada saat pengujian. Jika tidak terdapat respons, siswa perlu memeriksa koneksi fisik, konfigurasi IP, dan pengaturan firewall.

Alamat IP tersebut merupakan contoh simulasi, bukan konfigurasi perusahaan tertentu.

## Konfigurasi Router Saat PKL

Konfigurasi router merupakan kegiatan pengaturan perangkat jaringan untuk menghubungkan jaringan berbeda, mengelola pengalamatan perangkat, dan menyediakan konektivitas berdasarkan kebutuhan serta kebijakan jaringan perusahaan.

Pekerjaan siswa dapat mencakup pemeriksaan interface, pengaturan alamat IP, konfigurasi DHCP, dan pengujian konektivitas.

Siswa sebaiknya melakukan latihan menggunakan perangkat simulasi atau jaringan yang telah disediakan pembimbing.

Perubahan konfigurasi pada jaringan aktif harus memperoleh persetujuan karena kesalahan pengaturan dapat mengganggu pekerjaan pengguna lain.

## Bagaimana Menulis Troubleshooting Jaringan dalam Laporan?

Troubleshooting jaringan ditulis berdasarkan gejala gangguan, kemungkinan penyebab, langkah pemeriksaan, tindakan perbaikan, dan hasil pengujian setelah masalah konektivitas ditangani sesuai prosedur kerja.

| Gejala | Pemeriksaan | Tindakan yang memungkinkan |
|---|---|---|
| Kabel tidak terdeteksi | Konektor dan port | Memasang ulang kabel |
| IP tidak sesuai | Pengaturan adapter | Menyesuaikan konfigurasi |
| Gateway tidak merespons | Koneksi dan alamat gateway | Memeriksa pengaturan jaringan |
| Koneksi tidak stabil | Kabel dan perangkat | Menguji komponen jaringan |
| Domain tidak terbuka | Pengaturan DNS | Memeriksa layanan DNS |

Tindakan perbaikan harus disesuaikan dengan penyebab yang ditemukan. Jangan langsung menyimpulkan bahwa router rusak hanya karena komputer tidak dapat mengakses internet.
