Selama PKL (Praktik Kerja Lapangan) jurusan RPL (Rekayasa Perangkat Lunak), pekerjaan yang dilakukan siswa sangat bergantung pada jenis perusahaan atau instansi tempat mereka menjalani magang. Ada siswa yang mendapatkan tugas membuat website, mengembangkan aplikasi, mengelola database, hingga membantu pengelolaan teknologi informasi di sebuah kantor.

Jurusan RPL yang kini juga dikenal dengan nama PPLG (Pengembangan Perangkat Lunak dan Gim) mempersiapkan siswa untuk mempelajari pengembangan perangkat lunak, pemrograman, pengelolaan basis data, serta pembuatan aplikasi.

Di [PKL Di Saka Malang](https://www.pkldisaka.id/) yang diselenggarakan oleh **CV Saudagar Kaya Abadi**, siswa SMK jurusan RPL dibimbing langsung oleh tim pengembang dalam memahami ekosistem teknologi nyata, mulai dari slicing desain antarmuka, optimasi CMS, hingga pengujian sistem secara terstruktur.


## Apa Saja Pekerjaan Anak RPL Saat PKL?

Secara umum, pekerjaan siswa RPL selama PKL berkaitan dengan pengembangan dan pengelolaan perangkat lunak. Berikut beberapa tugas yang sering diberikan perusahaan atau instansi:

### 1. Membuat dan Mengembangkan Website
Membantu membuat atau memperbarui halaman website perusahaan menggunakan HTML5 semantik, CSS3 responsif, interaksi JavaScript, maupun PHP dasar. Tugas ini sangat umum ditemukan di agensi web dan software house.

### 2. Membuat atau Mengembangkan Aplikasi
Membantu pembuatan fitur aplikasi berbasis web atau desktop, seperti modul autentikasi (login/register), formulir input data, filter pencarian, dan perbaikan tampilan formulir inventaris.

### 3. Mengelola Database
Mempelajari pengelolaan basis data MySQL atau PostgreSQL, mulai dari perancangan tabel sederhana, eksekusi query CRUD (Create, Read, Update, Delete), hingga pengujian integritas relasi antardata.

![Siswa RPL melakukan pengujian aplikasi web dan pencatatan laporan hasil uji sistem](/images/blog/tugas-rpl-testing-aplikasi.webp)

### 4. Melakukan Testing dan Debugging
Menguji aplikasi secara manual (*Quality Assurance*) untuk memastikan fungsi tombol, validasi formulir, dan responsivitas halaman di berbagai browser berjalan lancar sebelum dilaporkan kepada tim developer.

### 5. Membuat Desain UI/UX Menggunakan Figma
Bagi siswa yang lebih tertarik pada estetika antarmuka, tugas pembuatan wireframe, mockup aplikasi, dan perancangan alur navigasi pengguna (*user journey*) menjadi opsi yang sangat relevan.

### 6. Menyusun Dokumentasi Sistem
Membuat diagram alir (*flowchart*), manual book panduan pengguna, serta catatan teknis pengujian yang sangat berguna sebagai bahan pendukung laporan akhir PKL di sekolah.

## Perbedaan Pekerjaan Anak RPL Berdasarkan Tempat PKL

| Jenis Tempat Magang | Fokus Tugas yang Dominan | Contoh Aktivitas Harian |
|---|---|---|
| Software House / Startup | Pengembangan software murni | Coding, debugging, Git version control, testing |
| Kantor Pemerintahan / Dinas | Pengelolaan data & portal web | Input data, update CMS berita, administrasi IT |
| Sekolah / Lembaga Edukasi | Pengelolaan sistem informasi | Update web sekolah, data nilai, perawatan lab PC |
| Perusahaan Non-IT / Retail | Operasional sistem digital | Rekap inventaris Excel, maintenance web produk |
