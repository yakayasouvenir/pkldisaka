Menjalani PKL di perusahaan IT menjadi kesempatan bagi siswa RPL untuk mengenal pekerjaan yang berkaitan langsung dengan pengembangan teknologi. Kamu tidak hanya belajar teori pemrograman di sekolah, tetapi juga berkesempatan melihat bagaimana website dan aplikasi dikembangkan dalam lingkungan kerja nyata.

Bagi Anda yang ingin mengasah keterampilan rekayasa perangkat lunak secara langsung, [program PKL industri CV Saudagar Kaya Abadi](https://www.pkldisaka.id/) di Kota Malang menyediakan ekosistem pendampingan harian oleh praktisi profesional agar siswa memiliki portofolio proyek yang dapat diandalkan.


## 10 Contoh Pekerjaan Anak RPL Saat PKL di Perusahaan IT

Berikut rincian 10 tugas yang paling sering dijumpai siswa RPL di software house maupun tim teknologi:

### 1. Membuat Tampilan Website dengan HTML dan CSS
Menyusun kerangka halaman profil perusahaan, landing page promosi produk, serta styling tombol dan formulir agar rapi dan responsif di smartphone.

### 2. Menambahkan Fitur Interaktif Menggunakan JavaScript
Menerapkan interaktivitas pada antarmuka web, seperti menu dropdown, pop-up modal konfirmasi, validasi karakter formulir, dan animasi navigasi.

### 3. Mengembangkan Fitur Website Berbasis PHP
Membantu tim backend membangun fungsi logika pengolahan data sederhana, proses autentikasi login, serta penanganan kiriman formulir ke server.

### 4. Mengelola Basis Data MySQL
Membuat skema tabel relasional, melakukan input data dummy untuk kebutuhan pengujian, serta menjalankan query seleksi data (*SQL Queries*).

![Siswa SMK RPL merancang prototipe antarmuka website menggunakan aplikasi Figma](/images/blog/pekerjaan-rpl-desain-ui-figma.webp)

### 5. Melakukan Pengujian Aplikasi (Quality Assurance)
Menguji skenario fungsi sistem secara menyeluruh, mencoba tombol dengan input yang salah, dan mencatat pesan error yang muncul (*bug reporting*).

### 6. Merancang Desain Antarmuka (UI) Menggunakan Figma
Mengubah ide kebutuhan klien menjadi mockup visual yang interaktif sebelum dieksekusi menjadi baris kode oleh tim programmer.

### 7. Mengelola Website Menggunakan CMS WordPress
Mengunggah artikel blog, memperbarui informasi kontak dan banner slider, serta mengoptimalkan aset gambar web tanpa perlu menulis kode dari awal.

### 8. Memperbaiki Kesalahan Program (Bug Fixing) Sederhana
Memperbaiki error minor seperti link halaman yang patah (*broken links*), teks tombol yang terpotong pada layar ponsel, atau kesalahan penulisan skrip.

### 9. Menyusun Dokumentasi Teknis Sistem
Menuliskan buku panduan pengguna (*manual book*), diagram relasi entitas (ERD), dan rangkuman alur sistem untuk memudahkan pengguna umum.

### 10. Membantu Pemeliharaan Website & Aplikasi
Melakukan pemeriksaan rutin terhadap status uptime website perusahaan, pembaruan plugin CMS, serta pencadangan berkas (*backup* data berkala).
