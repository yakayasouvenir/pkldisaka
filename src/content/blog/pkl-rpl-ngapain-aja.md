## PKL RPL Ngapain Aja? Ini Gambaran Tugas Nyatanya

Banyak siswa SMK kejuruan teknologi informasi yang bertanya-tanya sebelum berangkat magang: **PKL RPL ngapain aja** di tempat kerja?

Secara umum, tugas anak RPL saat PKL berkaitan erat dengan siklus hidup pengembangan perangkat lunak, mulai dari pembuatan, pengembangan fitur, pengujian antarmuka, hingga pemeliharaan sistem web. Jenis pekerjaan tentu disesuaikan dengan bidang usaha mitra industri dan proyek yang sedang ditangani.

Siswa yang mengikuti magang di software house, agensi digital, atau divisi teknologi perusahaan akan memperoleh bimbingan langsung dalam pemrograman web, database, maupun perancangan antarmuka visual.

Berikut rincian pekerjaan dan kegiatan nyata yang umum diberikan mentor industri:

### 1. Membuat dan Mengembangkan Website Menggunakan HTML dan CSS

Tugas paling mendasar dan utama saat PKL RPL adalah membangun halaman website. HTML digunakan untuk menyusun kerangka semantik dokumen, sedangkan CSS dimanfaatkan untuk mengatur estetika visual agar rapi, proporsional, dan nyaman diakses di berbagai perangkat pengguna.

Contoh tugas nyata yang biasa diberikan:

- Membuat halaman profil perusahaan (*company profile*).
- Menyusun halaman katalog layanan dan rincian produk.
- Membuat halaman kontak interaktif.
- Mengatur struktur navigasi menu yang mudah digunakan.
- Mengimplementasikan desain responsif (*mobile-friendly*).
- Memperbaiki tata letak halaman yang bergeser atau rusak.

Sebagai contoh, siswa diminta membuat halaman beranda website perusahaan yang menampilkan logo, ringkasan profil, galeri foto, dan tombol chat WhatsApp. Pekerjaan ini melatih pemahaman siswa mengenai hubungan antara struktur HTML5 dan tata letak CSS modern seperti Flexbox dan CSS Grid.

### 2. Menambahkan Interaktivitas Website Menggunakan JavaScript

Website modern tidak hanya membutuhkan tampilan yang menarik, tetapi juga fungsionalitas interaktif yang responsif. Melalui penugasan JavaScript, siswa mempelajari bagaimana halaman web merespons tindakan pengguna secara *real-time*.

Contoh pekerjaan yang diberikan:

- Membuat menu navigasi interaktif (*hamburger menu*).
- Menambahkan validasi formulir sebelum data dikirim ke server.
- Membuat fitur pencarian dan filter tabel sederhana.
- Menampilkan jendela pop-up notifikasi dinamis.
- Membuat komponen interaktif seperti slider banner atau accordion FAQ.
- Mengatur respons antarmuka berdasarkan klik atau input pengguna.

Melalui tugas ini, siswa memahami logika pemrograman *client-side* dan manipulasi DOM (*Document Object Model*).

### 3. Mengembangkan Fitur Backend Menggunakan PHP

Untuk mengolah data yang dinamis, siswa RPL diperkenalkan pada bahasa pemrograman *server-side* seperti PHP. Siswa belajar bagaimana data formulir diproses, diverifikasi, dan diteruskan ke database server.

Contoh fitur yang dapat dikerjakan:

- Membuat modul otentikasi login dan logout akun pengguna.
- Membuat formulir registrasi online peserta atau klien.
- Mengembangkan fungsi simpan data baru (Create).
- Membuat fitur edit dan perbarui data (Update).
- Membuat fitur hapus data (Delete).
- Menampilkan data dinamis dari server ke tabel antarmuka.

Misalnya, siswa mendapatkan tugas membuat formulir pendaftaran. Data yang dimasukkan pengunjung akan divalidasi oleh skrip PHP sebelum disimpan secara aman ke database.

### 4. Mengelola Database Menggunakan MySQL

Database merupakan fondasi penting dalam aplikasi untuk menyimpan seluruh informasi sistem secara terstruktur dan aman.

Siswa RPL belajar menggunakan MySQL untuk merancang dan memelihara skema data:

- Membuat database baru sesuai modul aplikasi.
- Membuat tabel dan menetapkan tipe data kolom yang tepat.
- Menentukan *primary key* dan *foreign key*.
- Menginput data awal dengan perintah SQL INSERT.
- Memperbarui informasi data dengan perintah UPDATE.
- Menghapus data usang dengan perintah DELETE.
- Merelasikan antartabel menggunakan klausa JOIN.

Contohnya, siswa membantu merancang database sistem informasi sekolah yang berisi tabel data siswa, guru, kelas, dan absensi harian.

### 5. Memperbaiki Bug dan Error Program (Debugging)

Debugging adalah proses menemukan penyebab kesalahan (*error*) pada baris kode dan memperbaikinya hingga program kembali berjalan normal.

Tugas ini sangat efektif melatih ketelitian, daya analisis, dan kemampuan pemecahan masalah (*problem solving*) siswa.

Contoh kendala yang sering ditemui:

- Tombol simpan tidak memberikan respons saat diklik.
- Formulir gagal terhubung ke database.
- Tampilan website rusak pada layar smartphone.
- Pesan kesalahan sintaks atau Fatal PHP.
- Hasil koding tidak sesuai dengan rancangan desain UI.

Siswa dibimbing cara membaca pesan error (*console log* dan *stack trace*), melacak baris kode yang bermasalah, dan menguji solusi perbaikan bersama mentor.

### 6. Merancang Desain Antarmuka Menggunakan Figma

Selain koding teknis, siswa RPL juga dilatih dalam perancangan antarmuka pengguna (*UI/UX Design*) menggunakan tools industri seperti Figma.

Figma digunakan untuk membuat rancangan tampilan visual sebelum diterjemahkan ke dalam kode HTML dan CSS (*slicing UI*).

Aktivitas desain yang dipelajari:

- Membuat kerangka dasar halaman (*wireframe*).
- Mendesain halaman login dan register yang intuitif.
- Menyusun tata letak *dashboard* administrasi.
- Memilih paduan warna kontras dan tipografi yang nyaman dibaca.
- Membuat prototipe antarmuka interaktif (*clickable prototype*).

Latihan ini membantu siswa memahami sudut pandang kenyamanan pengguna (*user experience*) sebelum mengimplementasikannya ke baris kode.

### 7. Melakukan Pengujian Aplikasi (Quality Assurance Testing)

Testing merupakan tahap krusial untuk memastikan seluruh fitur aplikasi bekerja sesuai standar sebelum diserahkan kepada klien atau diluncurkan ke publik.

Siswa menguji aplikasi dari sudut pandang pengguna, mencatat setiap kejanggalan atau bug, dan melaporkannya secara terstruktur kepada tim developer.

Daftar aspek yang diuji meliputi:

| Komponen Aplikasi | Fokus Pengujian Fungsional |
|---|---|
| Autentikasi Login | Memastikan akun sah dapat masuk dan akun salah ditolak |
| Formulir Pendaftaran | Memeriksa validasi karakter dan penyimpanan data |
| Halaman Dashboard | Memastikan seluruh metrik data tampil dengan akurat |
| Fitur Pencarian | Menguji keakuratan hasil filter kata kunci |
| Penyimpanan Database | Memverifikasi apakah data tersimpan di tabel yang tepat |
| Tampilan Responsif | Menguji kelancaran tampilan di layar desktop, tablet, dan HP |

## Apa Perbedaan Tugas Front End dan Back End Saat PKL?

Dalam dunia pengembangan software, pekerjaan umumnya terbagi menjadi Front End (sisi antarmuka pengguna) dan Back End (sisi server dan database):

| Aspek Penugasan | Front End Developer | Back End Developer |
|---|---|---|
| Fokus Utama | Tampilan antarmuka dan interaksi pengguna | Logika sistem, API, dan pengelolaan data |
| Bahasa Pemrograman | HTML5, CSS3, JavaScript | PHP, Python, Java, Node.js |
| Basis Data | Menerima data melalui API / JSON | Mengatur skema database dan query SQL |
| Tools Kerja | Figma, VS Code, Browser DevTools | VS Code, Postman, MySQL Workbench, XAMPP |
| Output Pekerjaan | Halaman web responsif, komponen tombol & menu | Endpoint API, otentikasi login, pemrosesan form |

Siswa yang tertarik pada estetika visual dan animasi interaktif dapat memfokuskan diri pada Front End. Sementara siswa yang menggemari logika algoritma dan struktur data dapat memperdalam peran Back End.

### Apakah Siswa RPL Bisa Mengerjakan Keduanya?

Bisa. Di banyak tempat magang yang fleksibel, siswa SMK RPL berkesempatan mempraktikkan keduanya (sebagai *Full Stack Developer* pemula) sehingga memperoleh pemahaman komprehensif tentang alur pengembangan web secara utuh.

## Contoh Proyek PKL RPL yang Nyata

Berikut beberapa contoh proyek nyata yang biasa diselesaikan siswa selama menjalani masa magang:

1. **Website Profil Bisnis (Company Profile):** Membangun website resmi yang memuat profil, daftar produk, galeri kegiatan, dan integrasi tombol pemesanan WhatsApp.
2. **Sistem Informasi Data Siswa:** Aplikasi berbasis web untuk mendata kehadiran, nilai, dan rekapitulasi data siswa dengan hak akses multi-level (Admin dan Guru).
3. **Aplikasi Presensi Karyawan:** Sistem pencatatan jam masuk dan pulang harian berbasis web dengan rekapitulasi data otomatis.
4. **Dashboard Administrasi Internal:** Panel navigasi bersih yang menampilkan ringkasan data statistik sistem secara berkala.

## Mengapa Penugasan PKL Perlu Disesuaikan Bertahap?

Di lingkungan magang yang profesional, mentor industri membimbing siswa secara berjenjang:

- Tahap awal: Memahami struktur HTML dan kerapian penulisan kode.
- Tahap lanjutan: Menerapkan styling CSS modern agar tampilan responsif di layar ponsel.
- Tahap pengayaan: Menambahkan fungsi interaktif dengan JavaScript dan menghubungkan skrip PHP ke database MySQL.
- Tahap akhir: Melakukan pengujian sistem (*QA testing*) dan mendokumentasikan kode untuk laporan PKL.

Metode bimbingan bertahap ini membuat siswa merasa nyaman, termotivasi, dan tidak terbebani oleh materi koding yang rumit.

## Statistik dan Pentingnya Pengalaman Kerja bagi Siswa RPL

Mempersiapkan diri menghadapi dunia industri sejak bangku SMK sangat krusial. Berdasarkan data resmi Badan Pusat Statistik (BPS) pada Mei 2025, jumlah angkatan kerja di Indonesia pada Februari 2025 mencapai 153,05 juta orang, dengan penduduk bekerja sebanyak 145,77 juta orang.

Pasar tenaga kerja yang besar menuntut lulusan kejuruan memiliki keterampilan terapan yang nyata. Praktik koding selama PKL memberikan bekal pengalaman berharga bagi siswa RPL dalam membangun portofolio kredibel untuk melangkah ke dunia kerja profesional maupun perguruan tinggi.
