## 1. Mengapa Portofolio Berbasis Studi Kasus Lebih Dilirik Industri?

Banyak siswa SMK dan mahasiswa pemula merasa minder saat diminta melampirkan portofolio karena merasa belum memiliki pengalaman kerja riil. Akibatnya, mereka sering kali hanya menumpuk gambar tanpa keterangan atau bahkan mengabaikan syarat portofolio sama sekali.

Di mata agensi digital dan industri kreatif, portofolio pemula tidak dinilai dari nama besar klien yang pernah ditangani. Mentor industri ingin melihat **alur pemecahan masalah (*problem-solving process*)**:
- Apa tantangan atau tujuan dari karya tersebut?
- *Tools* atau perangkat lunak apa yang Anda kuasai untuk menyelesaikannya?
- Bagaimana Anda mengeksekusi ide dari sketsa mentah menjadi hasil akhir yang fungsional?

Menampilkan 2 proyek dengan penjelasan proses yang jujur jauh lebih berharga daripada galeri acak berisi puluhan gambar tanpa cerita.

## 2. Struktur Anatomi Portofolio 1 Halaman yang Efektif

Agar portofolio Anda cepat dipahami dalam 30 detik pertama oleh reviewer, terapkan struktur 4 elemen esensial berikut:

1. **Header Identitas Ringkas:** Nama lengkap, jurusan, asal instansi sekolah/kampus, kontak WhatsApp, dan tautan profil publik (LinkedIn/GitHub/Behance).
2. **Karya Unggulan #1 (Best Work):** Tampilkan visual utama beresolusi tajam disertai ringkasan brief: *"Redesain Kemasan Kopi Lokal Malang untuk Menarik Pasar Anak Muda"*.
3. **Karya Unggulan #2 (Supporting Skill):** Tampilkan keahlian pelengkap, misalnya layout katalog produk, desain UI halaman login aplikasi, atau infografis data.
4. **Alat Kerja (*Tools Mastery*):** Cantumkan ikon perangkat lunak yang dikuasai secara realistis (Adobe Illustrator, Photoshop, Figma, VS Code, atau Canva Pro).

## 3. Sumber Karya Terbaik untuk Portofolio Siswa Tanpa Pengalaman

Jika Anda belum memiliki portofolio sama sekali, Anda dapat menyusunnya dalam 2–3 hari dengan memanfaatkan 3 sumber materi berikut:

- **Tugas Praktikum Sekolah Terpilih:** Pilih tugas gambar teknik, poster kegiatan sekolah, atau latihan coding yang pernah Anda kerjakan di laboratorium sekolah dan poles visualnya.
- **Redesain Sukarela Produk UMKM Lokal:** Datangi warung kopi, toko roti, atau usaha keripik di sekitar lingkungan tempat tinggal Anda. Buatkan konsep logo baru atau mockup kemasan yang lebih modern sebagai studi kasus portofolio.
- **Tantangan Desain Mandiri (*Design Prompt Challenge*):** Cari brief desain fiktif di internet (misalnya *Daily UI* atau *FakeClients*) dan selesaikan studi kasus tersebut dalam batas waktu tertentu.

## 4. Matriks Rekomendasi Format Portofolio per Jurusan

Sesuaikan format penyajian portofolio dengan rumpun keahlian jurusan Anda:

| Jurusan SMK / Vokasi | Bentuk Portofolio Utama | Format File Rekomendasi | Elemen Kunci yang Dinilai |
| :--- | :--- | :--- | :--- |
| **DKV & Desain Grafis** | Poster komersial, identitas logo, kemasan produk | PDF Presentasi (3–5 Halaman) | Sense of typography, harmoni warna, mockup visual |
| **RPL / Web Developer** | Tautan demo aplikasi, repositori kode sumber | GitHub + PDF 1 Halaman | Struktur logika kode, responsivitas mobile, kebersihan Git |
| **TKJ & Jaringan** | Dokumentasi topologi, setting router/server | Dokumen PDF Berfoto | Pemahaman IP addressing, konfigurasi mikrotik, kerapian kabel |
| **Bisnis Digital / Marketing** | Perencanaan kalender konten, copywriting iklan | PDF / Dokumen Presentasi | Riset tren hashtag, hook kalimat promosi, pemahaman target market |
| **Teknik Grafika** | Layout dieline cetak, proofing warna, prepress | Lembar PDF Dieline | Tanda potong (crop mark), bleed area, efisiensi bahan karton |

## 5. Checklist Evaluasi Mandiri Sebelum Portofolio Dikirim

Gunakan daftar centang berikut untuk memastikan berkas portofolio Anda bebas dari kesalahan teknis:

- [x] **Ukuran File Ringan:** Ukuran berkas PDF berada di bawah 5 MB sehingga tidak membebani kuota penerima.
- [x] **Navigasi Responsif:** Jika melampirkan tautan web/drive, pastikan sudah diuji buka di perangkat ponsel pintar.
- [x] **Bebas Plagiarisme:** Seluruh karya merupakan buatan sendiri atau hasil kolaborasi yang disebutkan peran spesifiknya.
- [x] **Kontak Jelas:** Tercantum nomor WhatsApp aktif dan alamat email di bagian atas atau bawah halaman portofolio.
- [x] **Format Teks Rapi:** Tidak ada kesalahan ejaan (*typo*) pada nama software atau istilah teknis kejuruan.
