## Ringkasan Inti

- Siswa RPL dapat mengerjakan tugas pengembangan website dan aplikasi digital.
- HTML, CSS, JavaScript, PHP, dan MySQL merupakan teknologi yang relevan untuk dipelajari.
- Tugas PKL disesuaikan dengan kemampuan siswa dan kebutuhan proyek industri.
- Siswa dapat mengenal proses kerja Front End dan Back End Developer secara bertahap.
- Hasil pekerjaan dapat menjadi portofolio bernilai tinggi jika mendapat izin perusahaan.

Pelajari selengkapnya mengenai gambaran kerja dan kurikulum industri di halaman [pkl rpl ngapain aja](/pkl-rpl-ngapain-aja/) serta program resmi [PKL di Saka](/) untuk bimbingan langsung dari mentor profesional.

## Apa Saja Tugas Anak RPL Saat PKL?

Tugas anak RPL saat PKL biasanya berkaitan dengan pembuatan, pengembangan, pengujian, dan pemeliharaan perangkat lunak. Jenis pekerjaan dapat berbeda sesuai bidang perusahaan dan proyek yang sedang dikerjakan.

Siswa yang mengikuti PKL di perusahaan pengembangan software dapat memperoleh tugas yang berhubungan dengan pemrograman web, aplikasi, database, maupun desain antarmuka. Lingkungan magang yang aplikatif membantu siswa menjembatani materi teori dari sekolah menuju standar industri sebenarnya.

Berikut beberapa contoh pekerjaan yang dapat diberikan mentor kepada peserta didik:

### 1. Membuat Website Menggunakan HTML dan CSS

Membuat website merupakan salah satu tugas yang dapat dikerjakan siswa RPL selama PKL.

HTML digunakan untuk membangun struktur halaman, sedangkan CSS digunakan untuk mengatur tampilan agar lebih menarik, rapi, dan mudah digunakan di berbagai resolusi layar.

Contoh pekerjaan yang bisa diberikan mentor:

- Membuat halaman profil perusahaan (*company profile*).
- Menyusun halaman informasi layanan dan produk.
- Membuat halaman kontak interaktif.
- Mengatur navigasi website yang ramah pengguna.
- Membuat tampilan responsif (*mobile-friendly*).
- Memperbaiki tata letak halaman yang bergeser.

Sebagai contoh, siswa diminta membuat halaman beranda website perusahaan yang menampilkan logo, informasi layanan, profil singkat, dan tombol kontak langsung ke admin. Pekerjaan ini membantu siswa memahami hubungan erat antara struktur HTML dan tampilan CSS modern.

### 2. Mengembangkan Website Menggunakan JavaScript

JavaScript digunakan untuk menambahkan fungsi interaktif pada halaman website statis.

Siswa dapat mempelajari bagaimana sebuah halaman merespons tindakan pengguna melalui tombol, formulir, menu dropdown, dan komponen interaktif lainnya.

Contoh tugasnya adalah:

- Membuat menu navigasi interaktif (*hamburger menu*).
- Menambahkan validasi formulir sebelum data dikirim.
- Membuat fitur pencarian data sederhana pada tabel.
- Menampilkan pesan notifikasi pop-up dinamis.
- Membuat komponen interaktif seperti slider banner atau accordion FAQ.
- Mengatur perilaku halaman berdasarkan input pengguna.

Dengan mengerjakan tugas tersebut, siswa memahami bahwa website tidak hanya membutuhkan tampilan yang menarik, tetapi juga fungsionalitas yang berjalan dengan mulus tanpa kendala teknis.

### 3. Membuat Fitur Website Menggunakan PHP

PHP merupakan salah satu bahasa pemrograman *server-side* yang paling umum digunakan untuk mengembangkan aplikasi berbasis web dinamis.

Siswa dapat diperkenalkan dengan proses pengolahan data dari formulir antarmuka hingga penyimpanan ke database server.

Contoh tugas yang dapat dikerjakan:

- Membuat proses otentikasi login dan logout akun pengguna.
- Membuat formulir pendaftaran peserta magang atau pelanggan.
- Mengembangkan fitur tambah data (Create).
- Membuat fitur edit dan hapus data (Update & Delete).
- Menampilkan informasi dinamis dari database ke tabel halaman admin.
- Mengembangkan halaman dashboard ringkas untuk monitoring data.

Misalnya, siswa mendapatkan tugas membuat fitur pendaftaran pengguna. Data yang dimasukkan melalui formulir antarmuka akan divalidasi, diproses oleh skrip PHP, lalu disimpan secara aman ke database.

### 4. Mengelola Database Menggunakan MySQL

Database merupakan bagian penting dalam pengembangan aplikasi karena digunakan untuk menyimpan seluruh informasi sistem secara terstruktur dan aman.

Siswa RPL dapat belajar menggunakan MySQL untuk membuat dan mengelola skema data relasional.

Beberapa pekerjaan yang mungkin diberikan adalah:

- Membuat database baru sesuai kebutuhan modul aplikasi.
- Membuat tabel dan menentukan tipe data setiap kolom.
- Menentukan *primary key* dan *foreign key*.
- Menambahkan data awal menggunakan query SQL INSERT.
- Mengubah informasi data menggunakan perintah UPDATE.
- Menghapus baris data usang dengan DELETE.
- Membuat relasi antartabel dan query JOIN untuk menampilkan relasi data.

Contohnya, siswa membantu mengembangkan database untuk sistem informasi sekolah yang berisi tabel siswa, kelas, guru, dan presensi harian.

### 5. Memperbaiki Bug dan Error Program (Debugging)

Debugging adalah proses menemukan penyebab kesalahan atau error dalam kode program dan memperbaikinya hingga berfungsi normal.

Tugas ini melatih siswa untuk berpikir logis, analitis, dan memiliki ketahanan dalam memecahkan masalah (*problem solving*).

Contoh masalah yang sering ditemukan di lapangan:

- Tombol simpan tidak memberikan respons saat diklik.
- Formulir gagal menyimpan data ke database server.
- Tampilan website rusak pada layar smartphone.
- Koneksi database terputus atau salah konfigurasi *credential*.
- Halaman web menampilkan pesan error Fatal PHP atau syntax error.
- Desain antarmuka hasil coding tidak sinkron dengan desain wireframe.

Siswa dapat mempelajari cara membaca pesan error (*stack trace*), memeriksa baris kode, dan menguji solusi perbaikan bersama mentor pembimbing.

### 6. Membuat Desain Website Menggunakan Figma

Selain menulis baris kode pemrograman, siswa RPL juga dapat diperkenalkan pada perancangan antarmuka (*UI/UX Design*) menggunakan tools modern seperti Figma.

Figma membantu membuat rancangan tampilan visual sebelum diimplementasikan menjadi susunan kode HTML dan CSS (*slicing UI*).

Tugas yang dapat diberikan meliputi:

- Membuat kerangka dasar halaman (*wireframe*).
- Mendesain halaman login dan register yang intuitif.
- Menyusun tata letak *dashboard* administrasi.
- Memilih kombinasi warna kontras dan tipografi yang mudah dibaca.
- Membuat prototipe interaktif (*clickable prototype*).
- Menyesuaikan elemen desain berdasarkan masukan dari mentor industri.

Kegiatan ini memberikan wawasan komprehensif bagi siswa mengenai kesinambungan antara desain antarmuka dan implementasi teknis di balik layar.

### 7. Melakukan Testing Aplikasi (Quality Assurance)

Testing merupakan kegiatan menguji aplikasi secara menyeluruh untuk memastikan seluruh fitur berjalan dengan lancar tanpa ada galat tersembunyi.

Siswa dapat mencoba aplikasi dari sudut pandang pengguna (*user perspective*), mencatat kendala yang ditemukan, dan menyampaikan laporan pengujian kepada tim developer.

Contoh daftar pengujian yang biasa dilakukan:

| Fitur Aplikasi | Fokus Pengujian |
|---|---|
| Autentikasi Login | Memastikan akun terdaftar dapat masuk dan akun salah ditolak |
| Formulir Registrasi | Memeriksa validasi karakter dan penyimpanan data baru |
| Tampilan Dashboard | Memastikan seluruh metrik data tampil dengan akurat |
| Kolom Pencarian | Menguji hasil filter kata kunci relevan |
| Penyimpanan Database | Memeriksa apakah data masuk ke tabel dengan benar |
| Responsivitas Layar | Menguji kelancaran tampilan di layar desktop, tablet, dan smartphone |

Pengujian yang dilakukan secara teliti dan sistematis membantu meningkatkan kualitas produk digital sebelum dirilis kepada publik.

## Apa Perbedaan Tugas Front End dan Back End Saat PKL?

Front End Developer mengembangkan tampilan visual interaktif yang langsung dilihat dan digunakan oleh pengguna, sedangkan Back End Developer menangani logika aplikasi, pemrosesan server, keamanan data, dan komunikasi dengan basis data.

Kedua bidang ini saling melengkapi untuk menghasilkan aplikasi yang utuh dan andal.

| Aspek Penugasan | Front End Developer | Back End Developer |
|---|---|---|
| Fokus Utama | Tampilan antarmuka dan interaksi pengguna | Logika sistem, API, dan pengelolaan data |
| Bahasa Pemrograman | HTML5, CSS3, JavaScript | PHP, Python, Java, Node.js |
| Basis Data | Menerima data melalui API / JSON | Mengatur skema database, query SQL, dan keamanan data |
| Tools Kerja | Figma, VS Code, Browser DevTools | VS Code, Postman, MySQL Workbench, XAMPP |
| Output Pekerjaan | Halaman web responsif, komponen tombol & slider | Endpoint API, fitur login, pengolahan data formulir |

Siswa yang menyukai unsur visual, estetika tata letak, dan animasi interaktif dapat memfokuskan diri pada Front End. Di sisi lain, siswa yang menyukai logika algoritma, pemrosesan data numerik, dan struktur database dapat memperdalam Back End.

### Apakah Siswa RPL Bisa Mengerjakan Kedua Bidang?

Sangat bisa. Siswa SMK RPL memiliki fleksibilitas tinggi untuk mempelajari dasar-dasar Front End sekaligus Back End selama masa PKL (dikenal sebagai *Full Stack Developer* pemula).

Pengalaman mencoba kedua peran tersebut selama magang industri sangat bermanfaat dalam membantu siswa menentukan arah karier spesifik yang ingin ditekuni setelah lulus sekolah.

## Bahasa Pemrograman Apa yang Harus Dipelajari Sebelum PKL?

Siswa RPL sebaiknya menguasai dasar-dasar HTML, CSS, JavaScript, dan konsep database relasional sebelum memasuki dunia magang yang berfokus pada pengembangan web.

Perusahaan software house atau agensi teknologi umumnya menggunakan kombinasi teknologi berikut:

| Nama Teknologi | Kemampuan Dasar yang Perlu Dikuasai |
|---|---|
| HTML | Menyusun tag semantik, form input, dan tautan halaman |
| CSS | Memahami box model, Flexbox, CSS Grid, dan media queries responsif |
| JavaScript | Menguasai manipulasi DOM, event listener tombol, dan kondisi logika |
| PHP | Memahami variabel, fungsi include, penanganan form method POST/GET |
| MySQL | Melakukan operasi dasar CRUD (Create, Read, Update, Delete) |
| Bootstrap | Memanfaatkan class bawaan untuk mempercepat perancangan tata letak |
| Git & GitHub | Melakukan commit perubahan kode, push ke repositori, dan branching |
| Figma | Membaca ukuran margin, jarak padding, dan aset icon dari desain mentor |

Siswa tidak dituntut untuk langsung menguasai seluruh teknologi secara mendalam sekaligus. Mulailah dari fondasi web dasar, lalu kembangkan secara bertahap sesuai kebutuhan proyek di tempat magang.

## Bagaimana Contoh Proyek PKL RPL yang Bisa Dikerjakan?

Proyek PKL RPL yang dikerjakan siswa biasanya berupa aplikasi fungsional yang membantu menyelesaikan kebutuhan operasional riil bagi bisnis, sekolah, atau UMKM.

Berikut beberapa contoh proyek nyata yang sangat relevan:

### 1. Website Profil Perusahaan (Company Profile)

Proyek ini bertujuan memperkenalkan identitas, portofolio, dan produk klien perusahaan secara profesional melalui website resmi.

Fitur yang biasa dibuat:

- Halaman beranda dengan banner interaktif.
- Halaman profil tentang kami dan tim perusahaan.
- Halaman etalase layanan atau daftar katalog produk.
- Galeri foto dokumentasi kegiatan kerja.
- Formulir kontak langsung yang terintegrasi dengan WhatsApp atau email.

### 2. Sistem Informasi Data Siswa

Aplikasi berbasis web yang digunakan untuk mendata dan mengelola rekapitulasi data siswa secara digital dan terstruktur.

Fitur yang dikembangkan:

- Otentikasi login multi-level (Admin dan Guru).
- Fitur input data siswa baru beserta foto profil.
- Fitur edit dan update identitas siswa.
- Filter pencarian data berdasarkan NISN atau nama kelas.
- Ekspor rekapitulasi data ke dalam format tabel rapi.

### 3. Aplikasi Presensi Karyawan Sederhana

Sistem pencatatan kehadiran yang membantu memantau kedisiplinan jam kerja secara transparan.

Fitur yang dapat dipelajari:

- Pencatatan jam masuk dan jam pulang secara otomatis.
- Riwayat kehadiran harian dan bulanan.
- Rekapitulasi status kehadiran (Hadir, Izin, Sakit, atau Alpa).
- Validasi lokasi atau catatan penugasan kerja harian.

### 4. Dashboard Administrasi Internal

Dashboard yang menyajikan ringkasan statistik dan metrik penting sistem dalam satu halaman navigasi yang bersih.

Siswa belajar cara menata komponen kartu ringkasan, membuat tabel dinamis dengan penomoran otomatis (*pagination*), dan menghubungkan antarmuka admin dengan query database MySQL.

## Mengapa Tugas PKL Perlu Disesuaikan dengan Kemampuan Siswa?

Penyesuaian tingkat kesulitan tugas oleh mentor industri sangat penting agar proses adaptasi siswa berjalan kondusif tanpa menimbulkan tekanan berlebih yang menghambat proses belajar.

Di lingkungan industri yang profesional, pembimbing memberikan penugasan secara berjenjang:

- Siswa pemula dibimbing menyusun kerangka semantik HTML5 yang rapi.
- Siswa yang mulai terbiasa dengan styling diarahkan merapikan tampilan menggunakan CSS responsif.
- Siswa yang menguasai dasar pemrograman diarahkan membuat interaktivitas menggunakan JavaScript.
- Siswa yang tertarik pada pengolahan data dibimbing mengonfigurasi skrip PHP dan database MySQL.
- Siswa yang menunjukkan ketelitian tinggi dilibatkan dalam proses pengujian kualitas antarmuka (*QA testing*).

Dengan kurikulum pembagian peran yang bertahap, rasa percaya diri siswa akan tumbuh seiring dengan bertambahnya portofolio proyek yang berhasil diselesaikan.

## Statistik dan Pentingnya Pengalaman Kerja bagi Siswa RPL

Pengalaman kerja langsung di lapangan menjadi salah satu aset terpenting bagi lulusan SMK vokasi agar siap bersaing di pasar tenaga kerja digital.

Berdasarkan data resmi Badan Pusat Statistik (BPS) pada Mei 2025, jumlah angkatan kerja di Indonesia pada Februari 2025 tercatat mencapai 153,05 juta orang, dengan penduduk bekerja mencapai 145,77 juta orang.

Besarnya pasar kerja tersebut menuntut calon talenta digital memiliki bukti kemampuan teknis yang konkret. Bagi siswa jurusan RPL, pengalaman menangani proyek koding nyata, memahami alur kerja tim developer, dan menyelesaikan penugasan industri menjadi modal berharga untuk melanjutkan karier profesional maupun menempuh pendidikan tinggi.

## Kesimpulan

Tugas anak RPL saat PKL mencakup spektrum kerja yang luas mulai dari coding, pembuatan website, pengelolaan database, perbaikan bug (*debugging*), perancangan antarmuka di Figma, hingga pengujian fungsionalitas aplikasi.

Sebelum memasuki masa magang, siswa disarankan memperkuat fondasi dasar HTML, CSS, JavaScript, PHP, dan MySQL. Di samping kemampuan teknis (*hard skill*), sikap disiplin, komunikasi aktif dengan mentor, dan kemampuan memecahkan masalah (*problem solving*) merupakan faktor kunci keberhasilan selama menjalani masa praktik kerja lapangan.
